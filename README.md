## 🌟 Key Features

### 📊 1. Academic Dashboard
- Instant visibility into your **Current CGPA**, **Total Credits Earned**, **Quality Points**, and **Target Progress**.
- Visual metric cards and status badges reflecting academic standing.

### 🧮 2. Dynamic GPA & CGPA Calculator
- Manage multiple semesters with customized course names, credit hours, and grade selections.
- Real-time recalculation of semester GPA and cumulative CGPA across all enrolled semesters.
- Standard 4.0 grading scale with full A+ through F grade point mappings.

### 🔮 3. What-If Scenario Simulator
- Test hypothetical grades before exams.
- Understand the exact impact of changing a grade in any course on your overall GPA.

### 🎯 4. Target GPA Planner
- Set a target graduation CGPA (e.g., 3.50 or 3.80).
- Automatically calculates the exact GPA needed across your remaining planned credit hours.
- Alerts you if a target is already achieved, challenging, or mathematically out of reach.

### ⚡ 5. Subject Priority Matrix
- Analyzes your course load to pinpoint which high-credit courses offer the greatest leverage for raising your CGPA.

### 📈 6. CGPA Journey & Analytics
- Visual semester-by-semester trajectory chart showing GPA progression over time.

### 🤖 7. Academic Advisor Chat
- Built-in advisor interface offering real-time recommendations, grade improvement strategies, and academic guidance.

### 🖨️ 8. Export & Print Ready
- Clean print modal to generate physical transcripts or save PDF summary reports.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gaytridevisaroop2023-hue/smart-cgpa-advisor.git
   cd smart-cgpa-advisor
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The compiled assets will be in the `dist/` directory.
